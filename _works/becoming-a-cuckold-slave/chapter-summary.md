## 情节结构发展（非线性）

全文不是顺叙，而是"先抛结局、再倒叙起因、最后答疑补完"的论坛连载结构：

1. **第 1–5 章｜顺叙铺垫（约 2008 起）**：恋足/奴性启蒙 → 借 SM 视频引入 → 地铁认主 → 岳母同住 → 孕期奴役。建立"脚奴 / 主人"底盘。
2. **第 6 章｜Flash-forward 结局**：直接跳到五年后的马尔代夫"绿帽生涯终结篇"，先把"三人行如何收场"抛给读者（吊钩）。
3. **第 7a–15 章｜回到起点的主线倒叙**：绿帽起因 → 妻自行出轨 → 第一次酒店伺候 → 巴西远程 → 正式离婚 → 三亚蜜月。强度与广度持续递增。
4. **第 16–17 章｜答疑体补完**：跳出叙事，用问答补齐杜姐线、各家关系、女主心路（2002–2018 四阶段）、复婚过程、Rachel 线与"难忘片段"合集。

贯穿全篇的象征道具：**CB6000 贞操锁、项圈狗链、过膝长靴、避孕套**（既是性具，也是绿帽调教的信物）。叙述者反复强调"叫停权在自己手里"，但实际上他是剧情真正的推手（女主多次点破"剧情都是你安排的"）。

## 调教发展（总弧线）

恋足前戏 → 贞操锁＋认主（脚奴确立）→ 权力外扩到岳母 → 绿帽（精神→肉体）→ 远程贞操控制＋离婚（性奴化）→ 群体化/公开化＋重度束缚 → 多主格局（杜姐假阳、Rachel 顶层、复婚后妻主夫奴）。

强度与广度单调递增，但取向偏**羞辱 / 绿帽 / 恋足 / 圣水**，而非血腥重刑；"升级"靠不断扩大参与者与公开度，而非加深肉体损伤。
