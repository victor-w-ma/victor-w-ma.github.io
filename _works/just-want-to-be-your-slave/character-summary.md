## 调教哲学（作者自述 + 原文锚点）

> 依据论坛 `forum-thread.md` 作者（chromaso）回复与正文 `full-text.md`，供各推演线（尤其 D 线）复用。

### 作者的「不可能三角」（impossible trinity，论坛楼层 395）

作者自陈本想同时达到三要素，但现实背景下**最多同时成立两个**：

1. **形象正面、深情而无私爱女主的徐**；
2. **形象正面、心底善良的吴**；
3. **越来越残忍的刑虐**。

读者各自牺牲不同一角：①垮＝徐「无耻匹夫」；②垮＝吴「利用徐的婊子」；弃③＝要求别再虐/弃坑。作者并自陈「不是我在控制情节，而是被情节牵着走」。

### 徐洋东的调教哲学（M 侧）

| 维度 | 内容（锚点） |
|------|--------------|
| 核心信条 | 「SM 才是最极致的表达爱的方式」「太爱→卑微→渴求做 M」（吴转述，full-text 874 / 9752） |
| 作者三解读 | ①不可靠叙事者藏无耻独占念头（作者不倾向）；②潜意识占有欲作祟（**作者现倾向**）；③**纯粹献身**、只想满足吴的施虐欲（作者**最初理想化设定**，现实背景下难令人信服）（楼层 395） |
| XP 错位 | 徐**更兴奋于羞辱**而非血腥，但吴给的是血腥（读者总结，楼层 ~705 / 9688） |
| 拆刹车 | 「就算把我虐伤虐残，你也不手软」——M 叫停权是唯一天然安全阀，徐却**主动放掉**（full-text 1922） |

### 吴小涵的调教哲学（S 侧）

| 维度 | 内容（锚点） |
|------|--------------|
| 职业性冷酷 | 因收费调教旧 M 的经验，养成「早已习惯的冷酷无情」（楼层 166 / 2210） |
| 正反馈机制 | 「一看到你求饶的样子，就突然更兴奋，忍不住更狠地折磨你」（full-text 1914） |
| 本性嗜虐 | 「我一直很喜欢玩刑讯」（full-text 2588）；「彻彻底底的抖 S」（full-text 402） |
| 把徐定位为纯 M | 「从没明示恋人……要把男主纯粹当一个 M 来看待」；曾考虑删「纯爱」tag（楼层 166 / 2208–2212） |
| 爱的来源 | 大学时仅淡好感，重逢后被徐成熟害羞的样子挑起爱恋（楼层 ~?，1760） |

→ **结构性后果：** 吴的「职业冷酷＋求饶正反馈＋耐受递增」使其施虐**结构性只能向上**，自我封顶＝背叛 S 本质；徐又主动弃用唯一的刹车（叫停权）。两者合力＝升级无界 → 不可逆毁灭，即②③不可兼得的机制根因。各推演线的「解法」本质都在回答：**这只失效的刹车由谁来接**（D 线＝外接男 S 作 governor）。

## 吴小涵 ↔ 苏玉

### 关系定性

**不是**双 S 平级，**不是**吴虐苏；而是 **姐妹 + 师徒 + 盟友**。

- **情感面：** 3.5 起互称姐妹，英文辩论队渊源，手挽手亲近。
- **权力面：** 吴是启蒙者、资源主、徐的所有者；苏是快速成长的独立女 S，魏的现主。
- **吴从未**把苏当 M 调教；**苏对吴**仅在雪地飞镖赌约中有一次游戏性支配（亲鞋）。

### 演变阶段

| 阶段 | 章节 | 要点 |
|------|------|------|
| 情敌 | 3.3–3.4 | 苏暗恋徐；吴疑暧昧重虐徐；苏救人顶撞 |
| 收编 | 3.5 教室 | 苏认输（「没有你的机会了」）；吴赠魏；教苏踩头收 M |
| 同台 | 3.5 夜–3.7 | 酒吧/雪地飞镖；苏赢一局；吴亲苏鞋尖；苏借徐舔鞋 |
| 副手 | 3.8 | 苏帮吴「监督」徐（实验室玩笑+威胁） |
| 分工 | 3.22–3.23 | 吴家乔迁；苏鞭魏两千，吴示范五鞭后旁观 |
| 反超（世俗） | 5A.10–12 | 婚礼、刑奴仪式；苏主虐魏；吴羡慕；苏震惊徐被阉程度 |

### 权力不对称（吴仍在上的理由）

1. **徐：** 苏表白后被宣判永久无机会；可「借」徐舔鞋，边界由吴定（「不许更过分了」）。
2. **魏：** 吴转让；魏称吴「唯一主人」；龟头历史为吴所割（5A 苏借此立威）。
3. **资源（SM）：** 调教室、器具在吴家；苏在吴场地调教魏。
4. **互动否决权：** 飞镖赌约吴拒「跪亲鞋」改「亲一下」；婚礼客房礼仪由吴决定徐跪否。

### 苏玉快速成长（用户归纳轴）

| 维度 | 变化 |
|------|------|
| 身份 | 3.5 当日「我不是做 S 的料」→ 当晚赌 M → 3.23 独立鞭魏 → 5A 设计刑奴婚礼 |
| 对魏 | 数日收奴 → 贞操锁 → 乔迁项圈电击 → 婚姻 + 全权虐夫 |
| 世俗资源 | 婚后借魏富二代家世：草坪婚礼、度假酒店、机票；**可调动社会资源** overtakes 吴（吴：买房、保险公司职员、无法给徐婚礼） |
| 对吴 | 赌局：吴骑坐徐身上前倾**唇碰苏鞋尖**后**起身站起**；苏借徐舔鞋底；吴醋意冻刑夺回徐 |

### 关键场景：雪地飞镖后倾斜（3.7）

**姿势链（正文可确定部分）：**

1. 吴**骑坐**徐身上扎睾丸 → 苏**站立**到吴面前。
2. 苏抬脚至吴嘴边；吴**唇碰鞋尖**（未写跪；苏已免「跪雪地」）。
3. 「亲完……吴小涵便**起身站了起来**」→ 从骑坐/低姿恢复直立。
4. 吴**站在一边**同意苏借徐；徐**跪**舔苏鞋底；吴醋意加码冻刑；双主**站徐背**自拍。

**论坛读者伏笔：** 有人提议若吴弱势，苏是「后起之秀」——与赌局亲鞋线呼应。
