## 〇、核心权力弧线（讨论定稿）

### 起点（前作结局）

```
赵立诚  >  林毅然  ⋙  其他人（冷瑞佳·苏潇潇·于琪昌…）
```

- 赵略高于林；林远高于其他所有人。
- 林占正室名分；冷受宠但无正室位；于琪昌为最底层马桶。

### 终点（续集要达成）

```
赵立诚  ⋙  林毅然  >  其他人（含冷瑞佳）
```

- **赵远高于林**，且**开始调教林毅然**。
- **林仅略高于其他人**（冷瑞佳不上位，仍在林之下）。
- 冷的「争位」是**杠杆/燃料**，不是成功上位。

### 引擎：赵借后宫斗争「分而治之」

1. 冷越想争宠 → 越讨好赵、帮赵调教他人 → 权力上交给赵当「裁判」。
2. 林为守位 → 也只能更卖力表忠 → 从「共治者」降为「被评分者」。
3. 赵给林的隐性契约：**向我服软，我保你永远压着其他所有人** → 林用「被赵调教」换「对下层的统治权」。
4. 对林的调教从**亲密/信任名义**滑坡起步，非一上来极端化。

## 二、林父知情度 Spectrum 与「反应一次」

**原则**：林父的权势可以一直在；**能否救林取决于林愿不愿意被救**。林替赵遮掩 = 同谋加深。

| 档位 | 林父知道什么 | 典型反应 |
|---|---|---|
| 1 | 完全不知 | 无 |
| 2 | 知恋爱，不知后宫/调教（**推荐主轴**） | 偶尔敲打名声 |
| 3 | 察觉女儿变了，不深究 | 装看不见（对照林对赵偷腥） |
| 4 | 知情且默许（利益联盟） | 默许甚至促成 |
| 5 | 完全知情且参与 | 极黑，慎用 |

**建议曲线**：档位 2 起 → 中段滑到 3 → 后段苏家事件触发 **L3** → 化解。

### 林父反应强度 × 化解

| 强度 | 触发 | 他做什么 | 化解 / 反制 |
|---|---|---|---|
| **L1** | 风言风语 | 口头敲打赵、提醒名声 | 林圆谎 + 赵做面子 |
| **L2** | 较实迹象（伤痕、告密） | 警告赵、派人盯梢、以照拂施压 | 林护赵；照拂反成「关系稳固」背书 |
| **L3** | 苏家曝光 / 怀孕 / 重伤 / 公开丑闻 | 要拆散、动关系收拾赵 | (a) 林反制：不配合、护赵；(b) 赵自立+把柄；(c) 赵父与林父谈利益捆绑；(d) 赵假意让步 |

**叙事功能**：L3 被化解后，坐实「**外人救不了替施虐者撒谎的女儿**」。

## 三、健身房 · 女学员线（优先）

**场景**：赵家独资健身房 = 帮派基地；**独立于林父**，是赵自立基本盘。

**对象**：赵立诚的**私教学员**（非教练线优先）。

**四阶段**（机制，非逐章）：

1. **训练立威**：严师—学员服从；规矩与罚则 normalize。
2. **体罚渐增**：「加罚」滑坡为体罚；用「严师/为你好」包装。
3. **性吸引**：体格魅力 + 近身纠正 + 体罚与性快感绑定。
4. **拿下调教**：越界 → 纳入底层；服从惯性 + 把柄 + 依赖锁死。

**与冷瑞佳区分**：冷 = 校园清纯 + 英雄救美；女学员 = **严师权威 + 训练服从**。

**旧角色接入**：冷当诱饵/同伙立功；于琪昌功能化（健身房幕后清洁/马桶/道具）。

**人设候选**（待定）：微胖自卑 / 产后焦虑 / 虚荣网红 / 备考学生 / 空虚白领。

## 四、苏潇潇 · 苏家极黑线（后段重锤）

**暴露**：苏母换班撞破 / 苏父赶回 / 送医露馅（原作：苏父外地、苏母三班倒、苏瞒父母）。

**苏家反应**：报警、找学校、找赵林家长、威胁曝光。

**上一辈联手拿下（极黑，已定）**：

1. **入所**：林父压流程（报警无果）；赵父罗织罪名/债务 → **苏家父母进看守所**。
2. **所内逼服**：短期可控屈服 → 撤诉、闭嘴。
3. **放出 → 性奴收编**：**赵父、林父两人**对苏家父母实施轮奸式「验收/收编」；确立**性奴层**。

**层级**：

- 赵父、林父：顶层（并列施虐；**平行调教层**）。
- 赵立诚：远高于林。
- 林毅然：略高于冷/苏/于/已服的苏家父母。
- 苏潇潇：退路断绝；待定与第三幕关系（旁观 / 被迫在场 / 事后才知）。
- 苏家父母：新纳入性奴；长期封口押金。

**与林父低知情兼容**：林父参与压苏家 = 「摆平闹事、保体面」，**不必等于知女儿被赵调教**（档位 2–3 可维持）。

**与 L3 合流**：苏家闹大 → 触发林父 L3 → 同时赵父+林父压服苏家 → 后段合成高潮。

**赵立诚位置**：第三幕**建议不在场**（上一代定规矩；家传逻辑）。

**待拍板**：苏父是否一并入所收编；苏潇潇与第三幕关系（旁观 / 被迫在场）。

## 五、九章分段方向（块级，非逐章细纲）

### 第十～十二章｜巩固与扩张

- 坐实结局新平衡；于琪昌「再开发」（制度化圈养 / 健身房功能化，二选一或并行）。
- 女学员线：**A 训练立威 → B 体罚渐增** 启动。
- 林父 **L1**；苏家暗线铺垫（苏母换班、小摩擦）。
- 赵对林的调教：**试探性**滑坡（名分发放权收归赵、林开始争宠焦虑）。

### 第十三～十五章｜变数与危机

- 女学员线：**C 性吸引 → D 拿下**；可收 1～2 名梯队对象。
- **苏家撞破 → 闹 → 两家联手入所 → 所内逼服**。
- 林父 **L2 → L3**（苏家或连带触发）；赵+林化解 L3。
- 林对赵服软加深；结构向「赵⋙林」明显移动。

### 第十六～十八章｜重排与终局

- **放出苏家父母 → 赵父+林父收编（极黑第三幕）**。
- 赵对**林毅然**调教**明显升级**；结构定格 **赵⋙林＞其他人（含冷）**。
- 女学员/苏潇潇/冷/于在新层级各就各位；可选：林坐实「略高于他人」的残余支配（验收、分配下层）。
